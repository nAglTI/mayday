## mayday 2.1.4

This release improves reconnect reliability and Android Quick Settings integration.

#### What's New

- Added better Android Quick Settings tile integration from the system tile settings screen.

#### Fixes

- Fixed a reconnect issue where the app could show the protected connection as active after turning it off and on, while traffic was not restored yet.
- Reconnecting now rebuilds the active connection more reliably before reporting it as ready.

#### Compatibility

- Android 10+
- APK includes native runtime for arm64-v8a.
- Recommended for users who noticed an active status after reconnecting without restored traffic.

## mayday 2.1.4

Этот релиз улучшает надежность повторного подключения и интеграцию с плиткой Quick Settings на Android.

#### Что нового

- Добавлена более корректная интеграция плитки Quick Settings с системным экраном настроек плитки.

#### Исправления

- Исправлена проблема повторного подключения, когда после выключения и включения приложение могло показывать активное защищенное подключение, хотя трафик еще не восстанавливался.
- Повторное подключение теперь надежнее пересоздает активное соединение перед тем, как показать его готовым.

#### Совместимость

- Android 10+
- APK содержит native runtime для arm64-v8a.
- Рекомендуется пользователям, которые видели активный статус после повторного подключения без восстановленного трафика.
