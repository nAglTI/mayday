## mayday 2.1.1

This release updates the Android app for the refreshed 2.0.3 connection runtime and improves compatibility with modern Mayday keys.

#### What's New

- Updated the bundled Android connection runtime to the refreshed 2.0.3 core.
- Added packet padding controls for advanced network protection.
- Added better preservation of extra connection hints imported with keys.
- Added support for relay aliases included in new keys.
- Added handling for future key versions so they are not overwritten silently.

#### Fixes

- Preserved extra data from modern imported keys more carefully when editing and saving settings.
- Kept advanced transport hints imported with a key instead of replacing the whole transport block.
- Kept relay alias data imported with a key across app restarts and settings saves.

#### Compatibility

- Android 10+
- APK includes native runtime for arm64-v8a.
- Older keys may need to be renewed when the app shows a compatibility warning.
- Modern keys are saved with the current config version and keep extra connection hints imported with the key.
- Keys from a future config version are not overwritten silently; the app asks for an update or a new key.

## mayday 2.1.1

Этот релиз обновляет Android-приложение под свежий runtime 2.0.3 и улучшает совместимость с современными ключами Mayday.

#### Что нового

- Обновлен встроенный Android-компонент подключения до свежего ядра 2.0.3.
- Добавлены настройки packet padding для расширенной защиты на сложных сетях.
- Добавлено более аккуратное сохранение дополнительных подсказок подключения из ключей.
- Добавлена поддержка relay aliases, которые приходят в новых ключах.
- Добавлено обработка ключей из будущих версий, чтобы приложение не перезаписывало их молча.

#### Исправления

- Дополнительные данные из современных ключей аккуратнее сохраняются при редактировании настроек.
- Расширенные транспортные подсказки из ключа сохраняются вместо полной перезаписи транспортного блока.
- Relay aliases из ключа сохраняются после перезапуска приложения и сохранения настроек.

#### Совместимость

- Android 10+
- APK содержит native runtime для arm64-v8a.
- Старые ключи может потребоваться обновить, если приложение показывает предупреждение о совместимости.
- Современные ключи сохраняются с текущей версией конфигурации и сохраняют дополнительные подсказки подключения, импортированные вместе с ключом.
- Ключи из будущей версии конфигурации не перезаписываются молча; приложение просит обновиться или получить новый ключ.
