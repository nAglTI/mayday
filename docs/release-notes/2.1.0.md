## mayday 2.1.0

This release updates the Android app around the new key-first setup flow, a quieter home screen, and clearer connection controls.

#### What's New

- Added key-only setup from pasted text, clipboard content, or a `mayday://import/...` link.
- Added a warning when a saved key is no longer compatible and must be renewed.
- Added automatic GitHub release checks with a small update banner.
- Simplified the home screen around connection status and user ID.
- Moved protocol, speed, endpoint, and technical details into expandable advanced diagnostics.
- Added a popup transport selector for long transport names and new transport options.
- Added network rescue and clearer advanced connection settings.
- Added automatic reconnect after saving connection settings while connected.

#### Fixes

- The connect button now shows a loader and stays locked while probing.
- Endpoint scores and latency now remain visible after the connection is established.
- Removed file and manual setup paths from onboarding.
- Save buttons now appear only after changes are made.
- Improved action text for saving app selection changes.
- Improved translated connection status labels.
- Removed extra visual noise and spacing from the main screen.

#### Compatibility

- Android 10+
- APK includes native runtime for arm64-v8a
- Older keys may need to be renewed when the app shows a compatibility warning.

Этот релиз обновляет Android-приложение под импорт через ключ, более спокойный главный экран и понятное управление подключением.

#### Что нового

- Добавлена настройка только по ключу: из вставленного текста, буфера обмена или ссылки `mayday://import/...`.
- Добавлено предупреждение, если сохраненный ключ больше не совместим и его нужно обновить.
- Добавлена автопроверка релизов GitHub с небольшим баннером обновления.
- Главный экран упрощен вокруг статуса подключения и ID пользователя.
- Протокол, скорость, endpoint-ы и технические детали перенесены в разворачиваемую расширенную диагностику.
- Добавлен всплывающий выбор транспорта для длинных названий и новых вариантов транспорта.
- Добавлены режим спасения сети и более понятные расширенные настройки подключения.
- Добавлено автоматическое переподключение после сохранения настроек подключения, если оно было активно.

#### Исправления

- Кнопка подключения теперь показывает лоадер и блокируется во время проверки.
- Баллы endpoint-ов и задержка теперь остаются видимыми после установки подключения.
- Из onboarding убраны импорт из файла и ручная настройка.
- Кнопки сохранения теперь появляются только после изменений.
- Улучшен текст действия для сохранения выбора приложений.
- Улучшены переводы статусов подключения.
- Убраны лишний визуальный шум и отступы на главном экране.

#### Совместимость

- Android 10+
- APK содержит native runtime для arm64-v8a
- Старые ключи может потребоваться обновить, если приложение показывает предупреждение о совместимости.
