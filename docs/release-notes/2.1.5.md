## mayday 2.1.5

This release updates the connection core and adds an optional app access journal.

#### What's New

- Updated the built-in connection core.
- Added applying settings to the active connection without unnecessary reconnects.
- Added the actual core version to advanced diagnostics, separate from the app version.
- Added Raw UDP v2 and Auto (low CPU) to the connection mode selector.
- Added packet padding presets: Off, Minimal, Extreme and Custom range with manual limits.
- Added an app access journal with categories, app details, JSONL export and history clearing.
- Journal recording is off by default. When enabled, it runs in the background with limited history and fewer repeated entries.

#### Fixes

- Fixed preferred-server selection during connection setup.
- Corrected priority handling for imported configurations.
- Keys using these connection modes can now be imported and keep the selected mode.
- Padding selections now override presets imported with a key, while preserving custom ranges.
- Fixed an imported network rescue option being ignored when connecting.
- Fixed cases where an app remained unidentified after a temporary lookup failure.
- Preserved unsaved app selections when returning from the access journal.
- Strengthened per-app checks when the connection owner cannot be identified.
- Removed inactive metrics and periodic quick-probe controls.

#### Compatibility

- Android 10+.
- ARM64 (arm64-v8a) devices.
- Raw UDP v1 is no longer supported. Select a supported mode or import an updated key; existing selections are not changed automatically.
- The journal shows observed access checks, not a complete record of connections. An entry outside your rules does not confirm successful unauthorized access.

## mayday 2.1.5

Этот релиз обновляет ядро подключения и добавляет журнал доступа приложений, который можно включить по необходимости.

#### Что нового

- Встроенное ядро подключения обновлено.
- Настройки применяются к активному подключению без лишних переподключений.
- В расширенной диагностике показана фактическая версия ядра отдельно от версии приложения.
- В выбор режима подключения добавлены Raw UDP v2 и «Авто (low CPU)».
- Добавлен выбор packet padding: Off, Minimal, Extreme и Custom range с ручными границами.
- Добавлен журнал доступа приложений с категориями, подробностями, экспортом в JSONL и очисткой истории.
- Запись журнала по умолчанию выключена. При включении она работает в фоне с ограничением объёма истории и сокращением повторных записей.

#### Исправления

- Исправлен выбор приоритетного сервера при подключении.
- Исправлена обработка приоритетов в импортированных настройках.
- Исправлен импорт ключей с этими режимами подключения; выбранный режим сохраняется.
- Выбранный режим padding теперь заменяет пресет из импортированного ключа, сохраняя ручной диапазон.
- Исправлено игнорирование дополнительной настройки Network rescue из импортированного ключа при подключении.
- Исправлены случаи, когда приложение оставалось неопределённым после временной ошибки поиска.
- Несохранённый выбор приложений сохраняется при возврате из журнала доступа.
- Усилена проверка доступа приложений, когда владельца соединения определить не удалось.
- Убраны неработающие переключатели метрик и периодической быстрой проверки.

#### Совместимость

- Android 10+.
- Устройства ARM64 (arm64-v8a).
- Raw UDP v1 больше не поддерживается. Выберите поддерживаемый режим или импортируйте обновлённый ключ; прежний выбор автоматически не меняется.
- Журнал показывает наблюдаемые проверки доступа, а не полную историю соединений. Запись вне выбранных правил не подтверждает успешный неразрешённый доступ.
