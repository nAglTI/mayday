## mayday 1.0.0

First release build of the mayday Android client.

#### What's New

- Fully refreshed app interface and visual style.
- Added onboarding for initial setup.
- Added a home screen with connection status, profile summary, and quick start/stop controls.
- Added connection profile settings.
- Added profile import from file, text, and clipboard.
- Added relay, server, DNS, MTU, and advanced connection settings.
- Added read-only display of the assigned user ID to protect server-bound configuration.
- Added split tunneling with app selection.
- Added a dedicated split routing screen.
- Added a Quick Settings tile for connecting and disconnecting from the system shade.
- Added notification actions for disconnecting and reconnecting without opening the app.
- Improved notification and Quick Settings icons for clearer connected and disconnected states.
- Added automatic language selection on first launch based on the system language.
- Improved connection status and startup error messages.
- Added Russian localization for the connection notification, Quick Settings, and connection controls.
- Updated the connection component.
- Improved protection against traffic bypass.
- Improved profile and settings persistence.
- Added release build setup with minification, resource shrinking, and versioned APK naming.

#### Fixes

- Fixed UI and navigation issues.
- Fixed build warnings.
- Improved profile import and saving.
- Fixed profile import in release builds.
- Improved notification behavior on devices with custom notification icon rendering.
- Removed unnecessary project files from the repository.

#### Compatibility

- Android 10+
- APK includes native runtime for arm64-v8a
